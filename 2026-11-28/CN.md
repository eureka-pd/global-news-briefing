## 3. 欧盟提出欧洲央行行长候选人，乌克兰贷款12月再议
**事实:** 欧洲理事会提出由巴勃罗·埃尔南德斯·德科斯出任下任欧洲央行行长。科斯塔表示，有24个成员国支持对乌追加贷款提案，12月将再讨论。欧盟也未就长期预算达成协议。 [3]

**分析:** 行长人选仍须征询欧洲议会及欧洲央行意见后正式决定。贷款也尚未得到最终批准。

## 4. 美军称在封锁伊朗港口期间再使一艘商船丧失动力
**事实:** 据美联社报道，美军27日表示，在阿曼湾使一艘试图突破伊朗港口封锁的商船丧失推进能力。巴基斯坦、沙特和土耳其官员在伊斯兰堡讨论地区安全。 [4]

**分析:** 商船事件的说法来自美军，不代表整个航道已关闭。

## 5. 铠侠与英伟达验证用 SSD 扩展 GPU 可用内存
**事实:** 铠侠欧洲27日表示，在一个 GB200 NVL72 机架上装配144块 NVMe SSD，提供约 1.1 PB 的原始存储容量。使用英伟达 SCADA 的概念验证显示，有望处理约两万亿个512字节向量。 [5]

**分析:** 1.1 PB 指的是 SSD 原始容量，不是机内 HBM。概念验证不等于商用发布或达到 HBM 性能。

## 6. GeekNews：谷歌调整 AI 代理访问 Workspace 的方式
**事实:** GeekNews 介绍了谷歌24日的公告。谷歌要求访问 Workspace 的 AI 代理使用官方 MCP 服务器或 CLI，技术执行自2027年2月1日开始。 [6]

**分析:** 开发者应检查依赖直接 REST 调用的代理功能。这不等于传统应用的 REST API 将全面关闭。
